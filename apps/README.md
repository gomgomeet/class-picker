> 안내: 같은 저장소 `standalone/README.md`

## 왜 옮겼나

정본 쪽이 같은 디자인(시안④ 캘린더 그리드)이면서 기능이 훨씬 앞서 있습니다.

| 항목 | 여기(아카이브) | 정본 `standalone/` (v4.6) |
|---|---|---|
| 노션 반영 | CSV 내보내 수동 가져오기 | **서버가 대신 등록** (`api/notion.js` — 토큰이 브라우저로 안 나감) |
| 구글 캘린더 | 없음 | **등록 + 1시간 전 알림** (`api/gcal.js`) |
| 날짜 | 저장 시각만 | **한국어 날짜 해석** ("다음 주 화요일 2시") |
| 긴 녹음 | 통째로 한 건 | **문장 자동 분리** |
| 녹음 안정성 | 기본 | 침묵 끊김 자동 재시작·마이크 진단 |
| 설치형 앱 | PWA 포장만 해 둠 | **실제 배포·설치해 사용 중** |

## 여기 있는 것

| 파일 | 설명 |
